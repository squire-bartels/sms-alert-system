# Contributing to ScheduleNotifier

Thank you for your interest in contributing!

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and write clear commit messages.
4. Ensure all code passes tests and linter checks.
5. Submit a pull request with a clear description of your changes.

## Code Style

- Follow best practices for JavaScript, HTML, and CSS.
- Use descriptive variable and function names.
- Write concise and clear code.

## Reporting Issues

Before submitting an issue, please:
- Search for existing issues.
- Provide detailed information and steps to reproduce.

## Pull Requests

- Link related issues in your PR description.
- Write clear, descriptive titles and commit messages.
- Ensure your branch is up to date with main before merging.

Thank you for helping improve this project!
